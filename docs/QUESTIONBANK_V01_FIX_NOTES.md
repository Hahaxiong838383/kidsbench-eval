## 为什么用「补丁层」而不是直接改表

原始 CSV（`questions/raw/`）**永不修改**——它是飞书表的版本快照。全部修复以补丁形式
落在独立文件里，转换时动态应用。这样：

1. **可审计**：每个补丁写明「问题是什么 / 为什么是问题 / 怎么修的」，人可逐条复核
2. **可重放**：飞书表更新后重新下载 CSV，补丁自动重放；若表内容已变化导致补丁失配，
   转换器显式报 `patch_failed`，不会静默出错
3. **可回滚**：删掉补丁文件即回到原始数据，零损伤

## 七类修法总述（按数量排序）

### A 类 · 时间平移（36 题）—— 最大修复类
**问题**：对话历史全标 `T+0`（今天），gold 也在 T+0。按协议 v1.1，当场对话在 LLM
上下文里，记忆系统无用武之地——这些题对记忆后端区分度为零。
**诊断**：逐题核对「根本目标」字段，36 题全部写着「跨天一致性」「昨日」「上次」——
出题意图本来就是跨会话，是时间标记笔误把『昨天的对话』写成了 T+0。
**修法**：对话历史与 gold 整段平移到昨天（`[T+0 ` → `[T-1d `）。内容一字不动。
**特例**：S09-⑤-007 是双日错位（把第一天写成 T+0、今天写成 T+1d），双重平移归位。

### A2 类 · 会话边界（2 题）
**问题**：同日多会话的题（下午聊完离座、晚上回来）按天切分切不开。
**修法**：S10-④-005 在两段之间插入会话分隔符 `---`；S04-④-010（15 分钟后重新入座）
打 `history_all_write` 标记——触发本身是新会话开始，全部历史按已结束会话写入记忆。
**原理**：协议的本质是「会话结束 → 记忆固化」，以会话为界而非以天为界。

### B 类 · 重标移出记忆轨（2 题）
S01-⑤-003（根本目标明示「同一会话中」）、S12-④-003（明示「超短期…即时」）——
这两题的设计意图就是当场，考的是生成端用好 context 的能力，不是记忆系统。
题目质量没问题，移出记忆评测轨道，归行为/一致评测（0-3 锚点判分）。

### C 类 · 周报文档型（5 题）+ C2 类 · 该遗忘型（3 题）
**C**：S08 五题的历史是『上周周报：…』文档文本而非对话。周报本质是小可在上周日晚
说的一段话 → 规范化为一条 `[T-7d 21:00] 小可: "…"` 的 assistant turn。
**C2**：S08-④-005/007/008 的 gold 为空**是设计意图**——题目考「周报不该翻出负面旧事」
（吵架/留堂/父母离婚），判分主体在答错雷区。机制化为 `judgment_mode=negative_only`：
gold 为空合法，判分只查雷区命中。注意：此类题差异主要在生成端选择性表达，
对记忆后端归因弱，报告时会标注。

### D 类 · gold 精确化（10 题）
**问题**：gold 是区间引用（『[T-7d]~[T-1d] 连续四条记录』）、印象改写（『妈妈答应带我去
迪士尼』vs 原句更长）、或单字确认句（『好』『嗯』——归因力为零且会误匹配）。
**修法**：全部改为与对话历史**一字不差**的精确引用；distributed 题逐句列出（`//` 分隔）；
信息在确认音里的（孩子说「好」），gold 改挂到信息承载句（小可的提议句）。
**铁律**：gold 必须原样引用历史中的句子，机器才能做归因（Attribution F1）。

### E 类 · 列错位重建（1 题）+ E2 类 · 字段补全（10 题）
**E**：S11-⑤-010 整行从「触发输入」起右移错位（批量填表事故）。六字段重建，
依据全在本行内：错位的内容互相印证 + 同场景同类题（S11-⑤-001/003）的字段值。
**E2**：fact_distribution 空值按 gold 形态机械判定（单句→single / 多句→distributed）。

## 转换器机制升级（修题暴露的需求）

1. **会话切分**：边界 = `---` 分隔符 **或** day_offset 变化（出题格式不统一，两个信号都认）
2. **gold 多句支持**：`//` 分隔的多条引用逐个定位，任一失败整体失败（宁缺勿错）
3. **gold 匹配分级**：≥4 字前缀包含匹配 / 恰 3 字必须整句精确相等 / <3 字拒绝（防误匹配）
4. **特殊题型标记**：`negative_only`（该遗忘型）/ `history_all_write`（触发即新会话）/
   `reclassify`（移出记忆轨）

## 给题库侧的三条出题铁律（防再犯）

1. **记忆题的 gold 必须位于 T-Nd 跨会话历史**；T+0 当场对话只营造场景，绝不承载 gold
2. **gold 必须原样引用**历史中的句子（一字不差），单字确认句不能当 gold——把 gold
   挂到信息承载句上
3. **distributed 题逐句列出 gold**（`//` 分隔），不写区间引用
